# 提瓦特文明史 · 网站

《提瓦特文明史与世界结构研究》的阅读与检索网站。研究本身（LaTeX 正文、证据、年表、图像）在独立的研究仓库里维护；这个仓库只负责把它变成网站。

## 它和一般 wiki 的区别

- **读本**：43 章连续正文。右栏随读到的段落同步列出该段引用的原文，点金色编号可定位到具体一条。
- **年表**：217 项事件，每个时间标明依据（文本纪年／近似年代／相对顺序／当代叙事），并可展开事件间的类型化时间关系。
- **星图**：研究引用过的每篇文本是一颗星，同一段论述里被一起引用的文本连成星座（十二个星座对应导论与十一卷）；点一颗星可读全文、看它支撑了哪些论述、常与哪些文本共引。
- **原文**：被引用的 580 余篇书籍、对白、角色故事的全文，引用句在文中标出并连回论述。
- **证据**：711 条短引，可检索、筛选，并反查每条在正文和年表中的引用处。
- **图版**：29 组图版与 2 幅结构图，逐幅附观察记录与来源。
- 任意页面按 `/` 全文搜索；支持昼／夜两套配色；移动端有底部导航与证据抽屉。

## 开发

```bash
npm install
npm run build     # content/ + src/ → dist/
npm run dev       # 构建并在 http://localhost:4173 预览
```

研究稿更新后，重新同步内容快照：

```bash
RESEARCH_DIR=../teyvat-research npm run sync
npm run build
```

`sync` 会复制正文与年表、裁剪证据字段、把图像压成 WebP，并写入 `content/`（已提交，因此站点仓库可以独立构建和部署）。

`sync` 还会按每条引证的定位，从固定版本的语料库 [DimbreathBot/AnimeGameData](https://github.com/DimbreathBot/AnimeGameData) 取回完整原文（需要联网；下载内容缓存在 `.cache/`，不入库），结果写入 `content/sources.json`。

## 结构

```
content/   研究仓库的内容快照（由 sync 生成）
scripts/   sync.mjs 同步 · build.mjs 生成 · diagrams.mjs 结构图 · serve.mjs 预览
src/       样式与前端脚本（无框架）
dist/      构建产物（纯静态，可部署到任意静态托管）
```
